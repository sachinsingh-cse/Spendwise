# 💰 Spendwise – Personal Expense Tracker

**Spendwise** is a user-friendly expense tracking application designed to help users manage, monitor, and understand their personal expenses. It provides an intuitive interface and visual insights to make expense management easier.

## ✨ Features

- **Expense Tracking:** Keep track of personal expenses.
- **Expense Analysis:** Understand spending patterns through visual charts.
- **User Authentication:** Firebase-based authentication support.
- **Interactive Dashboard:** View expense-related information in an organized interface.
- **Data Visualization:** Charts powered by ApexCharts.
- **Responsive UI:** Built with modern frontend technologies.
- **User Notifications:** Feedback through toast notifications.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js 18 | Frontend development |
| JavaScript | Application logic |
| React Router DOM | Navigation and routing |
| Firebase | Authentication and backend services |

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (comes with Node.js)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/sachinsingh-cse/Spendwise.git
```

### 2. Navigate to the Project Directory

```bash
cd Spendwise
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Firebase

The project includes Firebase integration. Configure your own Firebase project settings according to the Firebase initialization used in the `src` directory.

### 5. Start the Application

```bash
npm start
```

Open your browser and visit:

```text
http://localhost:3000
```
